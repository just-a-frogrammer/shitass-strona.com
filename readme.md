# Jak uruchomić stronę lokalnie (Linux)

<br>

## Installing flask

### Arch based (I use arch btw)
Might need sudo to execute
```bash 
Syu -S python3-flask
```
### Debian based (I use arch btw)
Might need sudo to execute
```bash 
apt install pyhon3-flask
```
### Fedora based (I use arch btw)
Might need sudo to execute
```bash 
dnf install pyhon3-flask
```

## Enter main project directory
```bash 
cd "location of the project's folder that you downloaded"
```

## Run the server
```bash 
flask run
```
